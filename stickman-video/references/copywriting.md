# 文案改写规则

## 输入
用户给的一句主题（如"不要用善良，去惯着得寸进尺的人"）或一段原始素材。

## 输出要求
- 约 **130–150 字**（对应 30–40 秒旁白；用户明确要求加长时可放宽）
- 拆成 **8 镜**（默认；用户指定镜数时照办），每镜 1–2 个短句
- 每镜标注：镜号 / 旁白文本 / 关键词（用于徽章）/ 画面动作描述

## 改写标准（爆款文案，不照搬）
1. **重组语言**：换意象、换顺序、换开头场景，不许直接照搬原文断句
2. **短句节奏**：多用短句，少用长复句；每句一个情绪点
3. **金句密度**：每 2–3 镜至少一句可单独摘出来当标题的金句
4. **情绪弧线**：压抑/共鸣（前 3–4 镜）→ 转折/觉醒（中 2 镜）→ 释然/升华（后 2 镜）
5. **口语化**：像对朋友说话，不书面、不说教

## 示例结构（8镜）
1. 钩子：反常识/扎心断言（例：善良，是一种选择，但不能没有底线。）
2. 共鸣：铺陈痛点/处境（对方的过分，或自身的委屈/麻木）
3. 共鸣：把痛点再推深一层
4. 低谷：情绪最低点
5. 转折：态度转变（拒绝/止损）
6. 觉醒：新的认知
7. 行动：具体做法（学会拒绝/转身离开）
8. 升华：祝福式收尾

## 关键词选择（徽章用）
每镜提炼 2–6 个字，最有冲击力的词。否定/打压/冲击类 → 1号爆炸气泡；
温暖/治愈/收尾类 → 2号云朵。
