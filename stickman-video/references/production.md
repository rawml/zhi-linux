# 制作流程：分镜 → TTS → 静帧 → 动画

## 项目目录结构
```
<project_dir>/
  audio/   narr01.mp3 … narrNN.mp3
  stills/  still01.png … stillNN.png   (2048×1152)
  anim/    anim01.mp4 … animNN.mp4     (10s, 1248×704)
  badges/  badge01.png … badgeNN.png   (透明底)
  output/  final_<name>.mp4
```

## 1. 分镜（导演逻辑写提示词）
每个分镜提示词必须定：场景 / 人物走位 / 道具 / 机位 / 色调 / 徽章留白。
镜1 必须是强钩子（冲突、对比、特写），不许平淡起手。
画面要饱满有信息量，上方留白放徽章。

## 2. TTS 旁白
用 Fish Audio（`~/workspace/skills/openmontage-muse/scripts/speak.sh`），逐镜合成：
```
bash ~/workspace/skills/openmontage-muse/scripts/speak.sh "该镜旁白文本" <音色名> <project_dir>/audio/narrNN.mp3
```
音色从 5 个实测中文音色里选（AD学姐 / 贾小军 / 温柔动听女声 / 宣传片大气浑厚 / 女大学生），**系列内锁定同一个音色**保证一致；换音色先跟用户确认。**当前锁定：女大学生**（2026-10-08 用户选定）。免费模型 s2.1-pro-free（免费至 2026-11-30，无 SLA）。
（旁白时长由 `bin/assemble.py` 自动用 ffprobe 实测，无需人工记录。）

**铁律：每段旁白合成后必须验证音频内容，不只验文件有效性。**
TTS 后端偶发中途截断（文件可播但只有前半句）。用语音转写（whisper 等）
逐段转写 narrNN.mp3，与该镜文案逐字核对：缺字、截断则重配，直到转写
与文案一致为止。组装前不做这一步，不得进入下一步。

## 3. 分镜静帧
`media.generate_video` 的图生视频需要首帧：用 `media.generate_image` 生成。
- 输入：男女角色参考图（kind:image）+ 文字描述
- **参考图来源**：首次使用本技能时，向用户索取男女火柴人参考图的路径；
  之后固定复用同一对参考图，保证全系列人物一致。没有参考图时先问用户要，
  不要自行设计人物。
- 尺寸：2048×1152（16:9）
- 每条提示词必须带 negative：
  `photorealistic, real person, photograph, realistic anatomy, detailed hands, 3d render, cinematic realism`

### ⚠️ 铁律：禁止纯白/空白背景（2026-10-03 补）
只写人物和动作，图片模型会默认输出白背景。这是别的 agent 用本技能时
最常见的翻车点。**每条静帧提示词必须按以下模板写满场景**：

```
[环境] 具体地点 + 时间 + 氛围（例：凌晨5点的卧室，窗外深蓝夜色）
[道具] 至少2-3个具体物件（例：床头闹钟显示5:00、被子、拖鞋）
[人物] 参考图角色 + 具体动作（例：男火柴人悄悄起床、手指竖嘴前做"嘘"状）
[光影色调] 光源 + 色调（例：床头灯暖光、冷蓝夜色对比）
[机位] 景别（例：中景）+ 上方留白放徽章
```

❌ 反例（会出白背景）："男火柴人举铁，汗水滴落"
✅ 正例（场景饱满）："昏暗健身房，男火柴人举杠铃过顶、汗水滴落；
背景是哑铃架和跑步机剪影，顶光打出一束光照亮人物，地面有杠铃片；
整体暗调、人物边缘有轮廓光；中景，上方留白"

- 目检（有一项不过就重做）：
  - 风格：圆头、点睛、细四肢、扁平色块、黑描边，无写实化
  - 人物穿着与参考图一致
  - **背景检查：画面有完整场景环境，不是纯白/空白背景**
  - 16:9 横构图，上方有徽章留白

## 4. 图生视频动画
`media.generate_video`，输入 still + 动作描述，约 10 秒。
- **动作描述要具体**：写清谁的哪个部位做什么（伸手、放下、转身、撕纸…），
  并声明"人物肢体有真实动作"
- **验证**：抽 t=1s 和 t=6s 两帧对比，确认肢体/表情/走位有真实变化；
  纯推镜/缩放/平移 = 不合格，重做（换更强动作描述）
- **目检**：无写实化/真人化/3D化；人物形象无严重漂移

## 已知坑与解法（2026-10-01 实战沉淀）
1. **男方红"H"帽字母漂移到女方帽上**：提示词里写"无字母"往往不够。
   有效解法：用图生图把男方改成离镜头更远/更小（字母不可辨认）后再生成动画。
2. **动作描述被平台拦截**：换更温和的表达重试一次
   （如"心变暗"→"捧心入怀、转失落为平静"）。
3. **第一版偏推镜**：换更强、更具体的动作描述重做一次。
4. 某镜实在无法生成动画时，保底方案：静帧推镜代替（需如实告知用户）。
