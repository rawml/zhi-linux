# 徽章 → 组装 → 质检

## 关键词徽章
`bin/make_badges.py <输出目录> <badges.json>`，badges.json 格式：
```json
[["不能没有底线", 1], ["留给值得的人", 2]]
```
- style 1 = 白色爆炸星芒 + 黑描边 + 黑色粗体字（否定/打压/冲击词）
- style 2 = 白色云朵 + 黑描边 + 黑色粗体字（温暖/治愈/收尾词）
- 字体：Noto Sans CJK SC Bold（脚本自动 fc-match 查找）
- 输出为透明底 PNG，组装时居中叠在画面上方（y=54）

## 组装
`bin/assemble.py <project_dir> <成片名>`，全自动：
1. ffprobe 实测每段旁白时长 → 每镜视频时长 = 旁白 + 0.5s
2. 每镜：animNN.mp4 缩放裁切到 1920×1080、30fps，叠加 badgeNN.png，
   按时长裁剪（无音频）
3. 每镜：narrNN.mp3 尾部补 0.5s 静音（apad），防音画累计漂移
4. 分别 concat 视频轨和音频轨，再 mux 成最终成片
   （H.264 + AAC，+faststart）
5. 输出 `<project_dir>/output/final_<成片名>.mp4`

**0.5s 静音垫是铁律**：早期版本越往后音画越不同步（第8镜差约3.5秒），
根因是每段旁白时长的小数部分累积；逐镜补齐后彻底解决。

## 质检清单（交付前逐项过）
- [ ] 1920×1080、30fps、H.264 视频 + AAC 音频
- [ ] 总时长 ≈ Σ(旁白时长 + 0.5s)，音频无断尾
- [ ] 逐镜抽帧：人物有真实动作（非纯推镜）
- [ ] 徽章：每镜关键词正确、清晰、不遮挡人物
- [ ] 人物形象：女（红绒球帽+宽松黄T恤）、男（红H帽+黄上衣+灰工装裤+红黑鞋），
      无写实化/真人化/3D化，无严重漂移
- [ ] 无旁白全文字幕（用户在剪映自行添加）
- [ ] 结尾无截断，情绪收束完整
